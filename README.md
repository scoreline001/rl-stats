# scoreline — RL Stats

A Windows desktop app that tracks your Rocket League **wins and losses**, teammates, and party/random matches — read from the stats socket Rocket League itself opens. No overlay, no memory reading, no injection.

## Download

- [scoreline-setup-1.0.0-x64.exe](https://github.com/scoreline001/rl-stats/releases/latest) — installer with automatic updates
- [scoreline-1.0.0-portable.exe](https://github.com/scoreline001/rl-stats/releases/latest) — runs anywhere, no install

## First run

1. Launch the app, go to **Settings → Your in-game name** and pick your name.
2. Open Rocket League once (with **Enable capture** on, or a DefaultStatsAPI.ini in the game's config folder).
3. Play — the app records every match.

Data lives in %APPDATA%\scoreline\.
