How it works

Three steps. Then it just runs.

scoreline doesn't hook the game or read its memory. Rocket League already opens a local stats socket, and scoreline simply listens to it.

Let the game write its config

Open Rocket League once so it creates its stats API file. scoreline finds it by itself on Steam and Epic.

Start scoreline

It connects to the socket the game opens on your own PC. Nothing is injected and no game files change.

Play

Every match lands in your history as it ends, and the live card keeps score while you play.

Straight talk

What it doesn't do.

An honest tracker is worth more than an optimistic one.

No touching the game

No injection, no memory reading, no game-file edits. Only the local stats socket.

No phoning home

No account, no server. Your matches stay in a folder on your PC, and you can export them any time. The one exception is optional and off by default: Discord Rich Presence, which only sends the two short lines it shows on your profile.

No rank or MMR

The game doesn't export it, so scoreline shows nothing instead of a guess (for now).

FAQ

Questions people ask first.

Is it safe? Does it change anything in the game?

It only reads. scoreline connects to the local stats socket Rocket League opens and never injects, reads memory or edits game files. Close the app and the game is untouched.

Why is there no rank or MMR?

The game doesn't export it. The stats contain wins, losses, goals and the like, but no rank. Rather than estimate, scoreline says so plainly.

Does it work with Steam and Epic?

Both. It checks your Steam libraries, the Epic launcher and your Documents folder. For an unusual install, add its TAGame\Config folder in Settings.

Where is my data stored?

On your PC, in %APPDATA%\scoreline. Nothing is uploaded, and you can export your history to JSON or CSV from the Matches tab.

Will Windows or my antivirus complain?

SmartScreen may say "unknown publisher" because releases aren't code-signed (a certificate costs money). Click More info → Run anyway. scoreline isn't open source, so download it only from GitHub Releases.

Which languages?

English and French, switchable in Settings.

What does the Discord status share?

Only what you can see on your profile: the mode and score while a match runs, then your last result and today's win/loss. It is off by default, needs a Discord application ID you create yourself, and is the app's only outbound connection. Turn it off in Settings whenever you like.
